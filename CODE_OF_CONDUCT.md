# Code of conduct

Be kind, be specific, assume good faith. Disagree with ideas, not people.

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Report unacceptable behavior to conduct@dogpolicies.com (until that mailbox
is live, open an issue marked "conduct" and a maintainer will take it
private). Maintainers may remove, edit or reject comments, commits, issues
and pull requests that do not follow it, and may ban repeat offenders.
